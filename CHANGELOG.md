# Changelog

## 1.0.0

- Gold Paladin (`#F5B000`) and gray Rogue (`#808588`) default class colors.
- Original Blizzard Wrath defaults for all other classes.
- Account-wide customization for every class through color pickers and exact hex commands.
- Shared class-color tables and change callbacks for compatible addons.
- ElvUI and Shadowed Unit Frames integrations.
- Built-in color reset commands and integration status output.

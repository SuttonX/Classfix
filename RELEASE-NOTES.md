# Classfix v1.0.0

Custom class colors for **WoW WotLK 3.3.5a**.

- Paladins use **gold (`#F5B000`)** and Rogues use **gray (`#808588`)** by default.
- All other classes retain their Blizzard Wrath colors.
- Customize any class with `/classfix`, or enter an exact hex color.
- Includes ElvUI and Shadowed Unit Frames integrations.
- Saves your chosen colors account-wide.

**Install:** Extract `!Classfix` from `Classfix.zip` into `Interface\AddOns`, then restart WoW.

**Settings:** `/classfix` or `/cf`.

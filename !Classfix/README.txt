Classfix - WoW WotLK 3.3.5a

Install !Classfix in Interface\AddOns and restart WoW.

Default colors: Blizzard Wrath colors, except Rogue #808588 and Paladin #F5B000.
All classes support account-wide custom colors.

/classfix                  Open class color settings
/cf                        Open class color settings
/classfix set rogue 808588  Set an exact RGB hex color
/classfix default          Apply Classfix defaults
/classfix blizzard         Apply Blizzard defaults
/classfix status           Show version and integration colors

Reload after changing colors to refresh addons that cache their palette.
Supports shared class-color tables, ElvUI and Shadowed Unit Frames.
Some addons with their own hardcoded colors may require additional support.
Use one global class-color addon at a time.
